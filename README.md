# Personal Portfolio Website

A responsive developer portfolio highlighting projects, technical capabilities, and interactive web experiences through custom styling and GreenSock (GSAP) animations.

**Live Deployment:** [usman-liard.vercel.app](https://usman-liard.vercel.app)[cite: 1]

---

## Overview

This repository contains the source code for my personal web development portfolio[cite: 1]. The site emphasizes clean visual hierarchy, performant code architecture, and interactive motion design to deliver an engaging user experience without relying on heavy external UI frameworks.

---

## Key Features

- **Interactive Motion Design:** Custom timeline-based scroll triggers, page load reveals, and element hover effects powered by GSAP.
- **Responsive Layout:** Adaptive user interface built from scratch to display consistently across desktop, tablet, and mobile displays.
- **Vanilla Architecture:** Developed purely with semantic HTML5, modern CSS3, and ES6 JavaScript to ensure minimal load latency and high lighthouse performance scores.
- **Structured Showcase:** Dedicated modules to highlight technical competencies, featured development projects, and contact channels.

---

## Built With

- **HTML5:** Semantic markup structure
- **CSS3:** Responsive layout systems (Flexbox, CSS Grid) and variable-based theming
- **JavaScript (ES6+):** Application logic and DOM manipulation
- **GSAP (GreenSock Animation Platform):** High-performance animation timelines and tween controls
- **Vercel:** Continuous deployment and web hosting[cite: 1]

## Getting Started

### Prerequisites

To view and edit the source code locally, you only need a modern web browser and a code editor (such as Visual Studio Code).

### Installation and Local Preview

1. Clone the repository[cite: 1]:
   ```bash
   git clone [https://github.com/Usman1487/My-Portfolio.git](https://github.com/Usman1487/My-Portfolio.git)
   cd My-Portfolio
   ```

2. Open the project directory:
   - Navigate to the `Front-end` folder[cite: 1].
   - Open `index.html` in your browser, or launch it using an extension like VS Code Live Server.
